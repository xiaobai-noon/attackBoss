## 五、视频层（8% 预算）

**当前 0 条。** 这是符合预期的 —— 视频层是最后才做的，而且只在剧本用 `"clip_candidate": true` 明确标注时才计入。

准入三条硬标准（全中才允许用视频，否则一律静态帧）：

1. 只在**立场反转**（关系/态度发生不可逆扭转）或**结局独白**；
2. 是**中近景**，不出现大幅肢体动作或走动；
3. 该台词的时长 ≥ 3 秒（太短的镜头不值得付转码与包体代价）。

技术红线：Godot 4 核心**只支持 Ogg Theora（.ogv）**，不支持 H.264 / WebM。可灵返回的 MP4 必须走 ffmpeg 转码：

```bash
# 1080p 30fps，Theora 是纯 CPU 解码，分辨率再高就得吃性能
ffmpeg -i in.mp4 -c:v libtheora -q:v 8 -c:a libvorbis -q:a 5 -r 30 out.ogv
```
